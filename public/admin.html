Each AI agent follows written instructions (its "prompt"). Edit them here and the live agents use the new version within 30 seconds. Every version is kept, so you can always go back. The reply format stays in the code, because the app has to be able to read the agent's answer.

Connectors are the tools and data sources each agent may use. Switch one off and the agent stops using it straight away, with no code change.

Adding functionality later. A new capability (for example, a bank-feed import or a payslip API) is added as one more connector: it is registered once in connectors.js with what it does, and it then appears in this table. The admin decides which agents may use it, and, if it needs no personal data, whether outside AI tools may use it through the MCP address. The agents themselves don't need rewriting.

Every analysis and review records numbers only: which agent ran, on the cloud or on this device, how long it took, and whether the coordinator accepted its answers. No document text is ever recorded.
